# Lilium Economic & Sustainability Analysis (Python Code)

This repository contains the full Python workflow used for the economic, sustainability, and elasticity analysis of **Lilium (Lilium spp.) cultivation** conducted under the **CSIR–Floriculture Mission (2021–2024)** across Himachal Pradesh, Uttarakhand, and Ladakh.

---

## 📘 About the Study
The analysis evaluates:
- Cost of cultivation under CACP framework  
- Net returns and benefit–cost ratios  
- Cobb–Douglas production elasticities  
- Regional heterogeneity (Himachal Pradesh, Uttarakhand, Ladakh)  
- Sustainability indices  
- Risk & variability (CV, CAGR, inter-year dynamics)  
- Gender participation  
- Visualization of system transitions and economic trends  

These codes correspond to the manuscript:

**“Economic and Sustainability Dynamics of High-Value Floriculture in Mountain Agriculture: Evidence from the Indian Himalayas.”**
